# Closeout

End every completed piece of work with these four sections, in this order. Write `None` when
a section has nothing real in it; do not invent content to fill a heading.

```markdown
**High confidence:** decisions made and recommendations given that you would defend with the
evidence in hand. One line each.

**Needs your guidance:** decisions you were not confident enough to make, each with the
alternatives and what is missing to choose.

**Questions:** what you need the project author to answer before the next step.

**What you should be asking:** the question the author has not asked that would change the
outcome most — one, stated plainly, with why.
```

Keep it short. The closeout is a record, not a report; the work above it is the report.
