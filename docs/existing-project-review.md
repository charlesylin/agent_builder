# Existing non-agent project adoption: review finding

Date: 2026-09-11

Author feedback: Agent Builder's framework is useful for AI projects beyond explicit
agent development. The author has an early but active Claude Cowork project assisting
with laboratory setup documents, protocols, procedures, and filing, and wants to bring
the framework into that project without restarting it.

## AB-R004: Evaluate adoption into existing projects

Status: proposed

Separate reusable project governance from software/agent deployment defaults. Evaluate
an adoption path that inventories current work, preserves approval evidence, proposes
the appropriate phase, and installs project-scoped instructions without overwriting
existing artifacts. The current initializer requires a new destination; it is not an
in-place migration tool.

The companion COWORK_EXISTING_PROJECT_ADOPTION.md is a proposed, manually adapted review
packet derived from the pinned v0.1 operating agreement. It is not a shipped generator
feature, validated scaffold, or approved new project profile.

Collect feedback on: accurate recovery of prior decisions, access to historical context,
phase mapping, instruction persistence, document lifecycle tracking, and unnecessary
software assumptions. Consider a reusable governance core and optional domain profiles
only after evaluating this evidence and obtaining scope/phase approval.

Agent Builder remains in Review. No generator, template, or confirmed decision changes.
